Accept card payments with OMPAY

OMPAY is a payment gateway for merchants in Oman. This module connects your Odoo store, invoices and sales orders to the OMPAY API so you can take card payments in Omani Rial and other currencies your OMPAY account supports.

The module is free for OMPAY merchants. You need an OMPAY merchant account to use it — your API credentials are issued once onboarding is complete.

Two checkout flows

  Bank Hosted (recommended) Merchant Hosted
Where the card is entered On a secure OMPAY page On your own checkout
PCI DSS scope SAQ A — card data never touches your server SAQ D — the heaviest compliance tier
Best for Almost every merchant Merchants already certified to SAQ D

Merchant Hosted stays switched off until you confirm your PCI compliance in the provider settings. Each flow is a separate capability on your OMPAY account.

What your customers see

With Bank Hosted, the customer is taken to a secure OMPAY page to pay, then returned to your Odoo store once the payment is confirmed.

The OMPAY payment page — card or OMPAY Wallet, with the order summary alongside.

Confirmation with a downloadable receipt. Odoo marks the invoice paid once the status is confirmed server-to-server.

What you get

3-D Secure 2
Full OTP support, including the browser data the authentication step requires.
Refunds from Odoo
Full and partial refunds, issued straight from the payment record. The remaining refundable balance is logged on the transaction.
Automatic reconciliation
A scheduled action re-checks unresolved payments every 30 minutes, so a customer who closes the browser mid-payment never leaves an order stuck.
Correct Omani Rial handling
OMR is a three-decimal currency. Amounts are rounded to the precision the currency actually uses, so what you charge matches what OMPAY settles.
Sandbox and production
A provider left in Test Mode uses the OMPAY sandbox; enabling it switches to the live API. No separate environment setting to keep in sync.
Status you can trust
The redirect back from OMPAY is never treated as proof of payment. Every outcome is confirmed by a server-to-server status inquiry.

Set up in four steps

  1. Install the module, then open Accounting › Configuration › Payment Providers and select OMPAY.
  2. Paste the API Key and API Secret that OMPAY issued you.
  3. Choose your checkout flow. Leave it on Bank Hosted unless you are PCI DSS SAQ D certified.
  4. Keep the provider in Test Mode while you verify with sandbox credentials, then set it to Enabled and swap in your production keys.

If your store prices in Omani Rial, check that the OMR currency is set to 3 decimal places under Accounting › Configuration › Currencies.

Requirements

  • Odoo 19.0 (Community or Enterprise)
  • An OMPAY merchant account with API credentials
  • The checkout flow you intend to use enabled on your OMPAY account
  • Self-hosted or Odoo.sh. Odoo Online does not permit third-party modules containing Python code.
